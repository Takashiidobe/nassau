# Grammar conformance fixtures

_2026-10-05 13:33:14_

Audited Nassau against Rossberg's SML'97 grammar page (https://people.mpi-sws.org/~rossberg/sml.html), one probe per production, compared with Poly/ML.

- tests/fixtures/grammar: 88 fixtures for productions that work, natively and in the interpreter.
- tests/fixtures/grammar.unsupported: 20 fixtures for 11 gaps, each header naming its bead (nassau-ugc.12-.22).
- tests/fixtures.rs: any *.unsupported/ directory is checked to be valid per Poly/ML and still failing in Nassau. When native and interpreter output both match Poly/ML, the trial fails and prints the git mv to the supported path.
- tools/update_filecheck.py: unsupported fixtures get Poly/ML-only CHECK-EXIT/CHECK-STDOUT, so they carry correct expectations when moved.

Gaps: \uXXXX escapes; nonfix symbolic ids; explicit tyvars in val/fun; op on longids; include with several ids; top-level exp; {} as unit type; substructure sharing in matching; infix constructors in expressions; op on built-in operators; flex record scope (a decision, since Poly/ML and MLton accept and SML/NJ rejects).

Syntax only: static and dynamic semantics and negative tests remain for nassau-ugc.11.
