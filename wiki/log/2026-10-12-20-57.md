# Complete OS.Process shutdown semantics

_2026-10-12 20:57:49_

Added the OS_PROCESS signature and retained the internal shutdown entry point.
Exit hooks are removed before invocation, so nested exit drains the remaining hooks.
Registrations during shutdown are ignored; escaping hook exceptions remain ignored.
Normal shutdown cleans up tracked TextIO file streams after hooks, including streams opened by hooks.
Closed streams are removed from the registry; standard output and error remain open.
OS.Process.terminate now uses a separate primitive backed by C _Exit, with native JIT and browser imports.
Fixtures cover signature matching, nested exit, hook termination, and stream cleanup; browser coverage runs them too.
