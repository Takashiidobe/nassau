# Prelude: SML basis loaded before user code, and structure List

_2026-10-05 19:58:58_

Basis modules are now SML source in basis/ (list.sml), embedded by src/prelude.rs. Files and the interpreter check the basis first in the same infer::Session (separate TypeTable, so --dump-expr-types shows only user nodes) and lower basis+user into one module with lower::Session::lower_parts, each part with its own Source so user line numbers do not shift. The REPL runs the basis as a hidden first chunk, also after reset;;. --dump-core lowers the user program alone to keep ids stable; programs needing basis structures cannot be core-dumped. structure List is complete (null length @ hd tl last getItem nth take drop rev concat revAppend app map mapPartial find filter partition foldl foldr exists all tabulate collate, plus Empty); top-level hd tl null rev @ foldr app are defined from it, which removed their Rust infer builtins and the earlier Rust List.filter IR. map/length/foldl stay Rust builtins. Added the Size exception (value.rs, constructors.rs, infer.rs). Newly passing: mlton 4, jump, lambda-list-ref (promoted); types valid-datatypes and valid-polymorphism lost their RUNTIME-SKIP; parser/valid-application now skips on unbound ~. New fixture tests/fixtures/runtime/list-structure.sml (Poly/ML oracle). Compile time of a trivial program is unchanged (~270ms, link dominated).
