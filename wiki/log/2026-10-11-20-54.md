# Drop the fixture suite from the release workflow

_2026-10-11 20:54:31_

The release workflow no longer runs cargo test --locked --test fixtures: ~980 fixtures at about a second each is too slow for a tag build. The tag-versus-Cargo.toml check moved into the release job so a mismatched tag still fails before a release is created. Release and per-platform binary jobs are unchanged. Tests are now only run locally (cargo nextest r --release).
