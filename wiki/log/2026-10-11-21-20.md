# Replace mmtk with a pure-Rust mark-sweep collector

_2026-10-11 21:20:14_

Dropped the mmtk dependency (it does not build on Windows) and rewrote runtime/gc.rs as a small non-moving mark-sweep collector in Rust.

- Objects are allocated with std::alloc and tracked in a hash set, which also screens out static literals when marking.
- The mark bit is 0x80 in the header's kind byte, set only during a collection.
- Roots are unchanged: shadow-stack frames, runtime with_roots scopes, globals, code globals, exception state.
- Collects when allocation since the last collection exceeds max(4 MiB, live bytes), or when the heap cap would be exceeded.
- NASSAU_GC_PLAN (NoGC|MarkSweep), NASSAU_GC_HEAP and NASSAU_GC_STRESS keep their meaning; sizes accept k/m/g suffixes.
- Removed the object-model Rust test and its binding fixture; renamed mmtk-* SML fixtures to gc-*.
- Also fixed the macOS link error: stdout/stderr are __stdoutp/__stderrp there.
- A moving collector was considered and rejected: generated code keeps using SSA values after publishing roots, so it would need reloads after every safepoint.
