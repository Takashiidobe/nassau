# Audit primitive IO, real, socket, and stream interfaces

_2026-10-10 18:43:45_

Audited the five Basis manual entries PrimIO, REAL, Socket, STREAM_IO, and StreamIO. Real currently implements only a subset; the remaining IEEE classification, sign-bit, decomposition, fused arithmetic, rounding, decimal, and math behavior is already tracked by nassau-617.26 and nassau-949.23. PrimIO and both stream interfaces require primitive readers/writers, OS descriptors, and byte/text arrays and vectors, covered by nassau-949.21, .949.13, and .949.14. Socket is optional and requires native socket handles and operations, covered by nassau-949.16. No accurate standalone SML behavior can fill these missing runtime boundaries; no placeholder code or duplicate runtime beads were added. Linked existing runtime issues to optional Basis audit nassau-617.5.
