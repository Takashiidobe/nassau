# Basis: List.filter

_2026-10-05 19:49:03_

Added List.filter as a built-in, following the Int.toString precedent: qualified name registered in infer.rs (('a -> bool) -> 'a list -> 'a list) and lowered in lower.rs by list_filter, a hand-built worker closure like map's. Kept elements are consed after a non-tail recursive call; dropped elements tail-call the worker. Works unapplied (val keep = List.filter) via builtin_closure. Fixture tests/fixtures/runtime/list-filter.sml covers empty/all/none, order, partial application, side-effect order, exceptions and a 20000-element list; expectations come from Poly/ML and it passes native and --interpret. There is no List structure yet, so List.* names are still flat builtins; String is missing too.
