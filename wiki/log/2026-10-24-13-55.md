# Stub sock_accept and sock_shutdown in the browser WASI shim

_2026-10-24 13:55:27_

The browser deploy failed to load: the runtime wasm imports sock_accept and sock_shutdown from wasi_snapshot_preview1 (pulled in by std's TCP code), but www/frontend/wasi.js did not define them. Added both as ENOSYS stubs. Checked every wasi_snapshot_preview1 import in nassau_runtime.wasm against the shim; these were the only two missing. Follow-up: nothing guards shim/runtime drift, so the next new std import will break the browser again.
