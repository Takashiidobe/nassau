# Audit POSIX process and primitive I/O interfaces

_2026-10-10 18:43:00_

Audited the next five manual entries: Posix.Process, Posix.Signal, Posix.SysDB, Posix.TTY, and PRIM_IO. Posix.Process.exit exists as a limited helper in basis/os.sml, but does not implement the specified process interface. The other POSIX structures need runtime process/signal, account database, and terminal services. PRIM_IO depends on OS.IO descriptors and runtime byte/text array/vector I/O; there is no faithful standalone SML implementation with the current Basis foundations. Existing runtime beads cover these needs: nassau-617.21, .617.24, .617.25, and .949.21. Linked them as dependencies of optional Basis audit issue nassau-617.5. No placeholder Basis code added.
