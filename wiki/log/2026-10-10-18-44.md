# Audit text and time Basis interfaces

_2026-10-10 18:44:31_

Audited the next five uncovered manual entries: SUBSTRING, TEXT, TEXT_IO, TEXT_STREAM_IO, and Time. The existing Substring implementation covers every operation in its declared signature; String and StringCvt are also already present in basis/sources. TEXT cannot be completed until the character array and slice structures can be built on the array/vector runtime (nassau-949.13). TEXT_IO and TEXT_STREAM_IO require primitive readers/writers, buffer representations, and stream operations (nassau-949.13, .949.14, .949.21). Time requires fixed-point time and clock support (nassau-949.20), with large integer precision relevant to conversions (.949.22). These requirements are already tracked, so no duplicate runtime beads or placeholder code were added. Linked the required Basis collections/I/O issue nassau-617.3 to primitive I/O runtime bead .949.21.
