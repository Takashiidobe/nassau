# OS.Process system, atExit, terminate and sleep, with a minimal Time

_2026-10-12 12:28:52_

OS.Process now has system (sh -c natively, SysErr in the browser), atExit, exit (runs hooks), terminate (skips them) and sleep. Hooks are an SML list in basis/os.sml run LIFO, exceptions swallowed and hooks added during exit ignored, as in Poly/ML; compiled programs get a trailing OS.Process.runAtExit part in main.rs (named after the user file so uncaught exception locations stay right), the REPL runs hooks only on exit. basis/time.sml is a small Time over real seconds, sealed with type time, for sleep and now. Rust: nassau_os_system, nassau_os_sleep, nassau_os_now; wasi.js implements poll_oneoff clock subscriptions (Atomics.wait when SharedArrayBuffer exists, else a spin). Fixtures: runtime/os-process-at-exit, -exit-hooks, -terminate and basis/process.sml match Poly/ML; browser-session.mjs covers sleep, system failure and exit hooks.
