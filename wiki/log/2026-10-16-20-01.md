# OS.FileSys access, rename, times, paths and tmpName

_2026-10-16 20:01:39_

OS.FileSys gains access (with access_mode), rename, modTime, setTime, isLink, readLink, fullPath, realPath and tmpName through eight more EXTERN_FNS rows over std::fs in runtime/os.rs. FileSys moved after Path in basis/os.sml so realPath can use Path.mkRelative. Text results (readLink, fullPath, tmpName) return "=value" or a decimal errno, since a string cannot carry a negative code. access probes with File::open/OpenOptions rather than uid-aware checks, and treats exec as a mode bit (directories on wasi). fullPath is canonicalize natively and a lexical walk plus an existence check on wasi. tmpName creates the file under TMPDIR or /tmp, creating /tmp on wasi. wasi.js nodes now carry an mtime, and the shim gains fd_filestat_set_times, path_rename and path_readlink (always EINVAL; it has no symlinks). tests/fixtures/basis/filesys-meta.sml matches Poly/ML and also runs in browser-session.mjs. Still missing: fileId/compare/hash, and symlink creation. modTime/setTime use the minimal real-backed Time, so nassau-949.20 may revisit precision.
