# Disable color in the nested cargo builds

_2026-10-11 20:47:34_

The release workflow failed in build.rs ('rustc reports native libraries for the runtime staticlib'): GitHub Actions sets CARGO_TERM_COLOR=always, the nested cargo inherited it, and rustc's native-static-libs note came out wrapped in ANSI escapes so strip_prefix on 'note: native-static-libs: ' never matched. Reproduced locally with CARGO_TERM_COLOR=always. Both nested cargo invocations now set CARGO_TERM_COLOR=never. Verified a cold cargo test --locked --test fixtures --no-run with forced color in a fresh target dir.
