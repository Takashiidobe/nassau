# Math via table-driven libm prims

_2026-10-12 11:22:16_

Added MATH_FNS in src/core.rs: a table of (SML name, libm symbol, arity). One Prim::Math(index) covers all of them. infer.rs registers each as Prim.mathXxx, lower.rs maps them to Builtin::Math (selecting tuple fields for arity 2), codegen.rs unboxes the reals, calls libm via call_c and reboxes; sqrt is inline cranelift. basis/math.sml now defines sqrt..tanh from these. New fixture tests/fixtures/basis/math.sml. Removed the mlton fixture directories: polyml is the only oracle. tools/import_suite.py is now orphaned. Top-level abs is still unbound.
