# OS.FileSys getDir and chDir, and parent paths in the browser shim

_2026-10-12 12:18:39_

getDir and chDir are two more EXTERN_FNS rows over std::env; wasi-libc already keeps the working directory on wasm32-wasip1, so no emulation is needed. wasi.js directories now carry a parent so .. resolves (it was skipped before). wasi-libc stores the cwd as an unnormalized string, so chdir .. left /a/b/.. and a later relative path walked through a removed directory; chDir now re-sets the lexically normalized directory and getDir returns it. filesys.sml covers relative files, .. paths and chDir errors against Poly/ML and in browser-session.mjs.
