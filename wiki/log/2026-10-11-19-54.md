# Precompile the native REPL Basis

_2026-10-11 19:54:06_

Native builds now run a source-shipped bootstrap compiler for the target architecture and link the compiled Basis archive. REPL startup and reset import its functions, mutable globals, and precomputed GC dependencies instead of JIT-compiling the Basis. Each initialization clears and rebuilds Basis values; user phrases still use the JIT. The browser backend keeps its existing load path. Added GC coverage for saved String.map after structure shadowing and Basis use after reset. Documented package verification in basis/README.md. cargo package --allow-dirty, Clippy, formatting, diff checks, and the wasm32 web check pass. Full release suite: 951 passed, 32 stale unsupported MLton classifications remain under nassau-3i7. Idle startup: about 0.2s release and 0.8s debug; previous binaries take about 0.75s release and 7.5–7.8s debug. Type checking and lowering still rebuild the compiler environment at startup; further reduction is tracked in nassau-4hq. Closed nassau-t6l. Preserved the existing package-version and MMTk manifest edits.
