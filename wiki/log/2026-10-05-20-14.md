# ~ as a function and prefix operator

_2026-10-05 20:14:03_

~ now type-checks: infer.rs types the name ~ as an overloaded (int, word, real) x -> x, like mod. Lowering already negated applied ~ on int/real; the value form (map ~ xs, op ~) was int-only, so typed_builtin in lower.rs now picks Builtin::NegateReal from the operand type for both the applied and the value site, and rejects word with an unsupported error like other word arithmetic. New fixture runtime/negation.sml; removed RUNTIME-SKIP from parser/valid-application and valid-operators; promoted mlton tststrcmp. Remaining RUNTIME-SKIPs: user infix constructors (++) and word arithmetic.
